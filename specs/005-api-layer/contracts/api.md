# API Contract: FinFolio Read API (v1)

Base URL: `http://127.0.0.1:8000`. No authentication (FR-012). Interactive docs at `/docs` (Swagger UI) and the raw schema at `/openapi.json`, both generated by FastAPI.

All responses are JSON. Stored fields are returned as stored (FR-015).

## Error shape

FastAPI's default for validation errors (422) and `HTTPException` (404, 500):

```json
{ "detail": "..." }
```

Validation errors name the invalid field and value. Examples:

- 422 bad verdict: `"verdict": "Partly true" is not one of True, Partially supported, Unverified, False`
- 422 bad date range: `"start" (2026-09-10) is after "end" (2026-09-01)`
- 422 bad video ID: `"video_id" must match ^[A-Za-z0-9_-]{1,64}$`

## Digests

### `GET /digests`

Lists all monthly digests, newest month first. Empty storage returns `items: []` (not an error).

Response `200`:

```json
{
  "items": [
    {
      "month": "2026-08",
      "generated_at": "2026-10-12T23:08:33.605781Z",
      "report_count": 2,
      "verdict_breakdown": {"True": 8, "Partially supported": 0, "Unverified": 133, "False": 0}
    }
  ]
}
```

### `GET /digests/{year}/{month}`

Returns one full monthly digest.

| Param | Location | Rules |
|---|---|---|
| `year` | path | 4-digit integer |
| `month` | path | integer 1–12 |

Responses:
- `200`: full digest as stored (`month`, `generated_at`, `report_count`, `verdict_breakdown`, `per_channel_breakdown`, `monetization_summary`, plus `disclaimer` once the pipeline writes it).
- `404`: `"No digest for 2026-07"`. Not a server error (spec US1-3).
- `422`: month outside 1–12, or year not 4 digits.
- `500`: stored digest file is unreadable; the detail names the file.

## Reports

### `GET /reports`

Lists per-video reports, newest fact-check first, with filters and pagination. All filters are optional and combine with AND.

| Param | Type | Rules |
|---|---|---|
| `channel` | string | Exact match on channel name or channel URL |
| `start` | date `YYYY-MM-DD` | Inclusive lower bound on the UTC fact-check date |
| `end` | date `YYYY-MM-DD` | Inclusive upper bound on the UTC fact-check date. Must not be before `start` |
| `verdict` | enum | One of `True`, `Partially supported`, `Unverified`, `False` |
| `page` | int | Default 1, minimum 1 |
| `page_size` | int | Default 50, minimum 1, maximum 200 |

Response `200`:

```json
{
  "items": [
    {
      "video_id": "-OYNQ74oG9k",
      "title": "...",
      "channel_name": "...",
      "channel_url": "...",
      "fact_checked_at": "2026-10-12T22:19:57.384033Z",
      "claim_count": 21,
      "verdict_breakdown": {"True": 1, "Partially supported": 0, "Unverified": 18, "False": 2}
    }
  ],
  "total": 1,
  "page": 1,
  "page_size": 50
}
```

- A page past the last page returns `items: []` with the real `total` (spec clarification, FR-003).
- No matches returns `items: []`, `total: 0`.
- `422` for an invalid `verdict`, an invalid date, or `start` after `end`. Missing one bound is treated as open (spec edge case).

### `GET /reports/{video_id}`

Returns one full per-video report.

| Param | Location | Rules |
|---|---|---|
| `video_id` | path | `^[A-Za-z0-9_-]{1,64}$` |

Responses:
- `200`: full report as stored (verdicts, summary, cost, disclaimer, transcript source, and the rest).
- `404`: `"No report for video ID abc123"`.
- `422`: malformed video ID.
- `500`: stored report file is unreadable; the detail names the file.

## Index

### `POST /index/refresh`

Rebuilds the index from the stored files and swaps it in (FR-010). Requests keep using the old index until the swap. Does not modify stored data (FR-011).

Response `200`:

```json
{
  "indexed": {"reports": 4998, "digests": 24},
  "skipped": [
    {"item": "storage/reports/videos/abc.json", "reason": "Invalid JSON"}
  ]
}
```

Malformed files appear in `skipped` and are logged; they do not stop the refresh (FR-014).
